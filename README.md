## Run Locally

To view or modify the portfolio locally:

**1. Clone the repository**

```bash
git clone https://github.com/areej0345/areej0345.github.io.git
```

**2. Navigate to the project directory**

```bash
cd areej0345.github.io
```

**3. Open the website**

Open `index.html` in your preferred web browser.

No additional dependencies or build tools are required.

## Deployment

This website is deployed using **GitHub Pages**.

To publish updates:

1. Make the required changes to the project files.
2. Commit and push the changes to the `main` branch.
3. Ensure GitHub Pages is configured to deploy from the `main` branch.
4. Visit the live website to view the published changes.
